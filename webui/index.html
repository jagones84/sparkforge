Harness · comportamento dell'agente

Runtimegiri di continuazione
Quante volte l'agente può continuare da solo prima di fermarsi: tiene in vita i lavori lunghi senza restare bloccato per sempre.
Verifierapplica solo se verde
Dopo le modifiche esegue un comando di verifica (es. i test) e le applica solo se passa: se fallisce, annulla.
Best-of-Npiù risposte, la migliore
Genera N risposte indipendenti e tiene la migliore: più affidabile, ma più lento e costoso.
Difficultysforzo adattivo
Adatta quanti tentativi fare in base a quanto è difficile il task: pochi se è facile, di più se è complesso.
Self-evolvingnuove skill
Riconosce i pattern ricorrenti nei tuoi task e propone di salvarli come skill riutilizzabili.

GitHub access

The agent uses GitHub through the official GitHub MCP server (remote https://api.githubcopilot.com/mcp/). Create a fine-grained Personal Access Token (scopes: repo, read:org, optionally workflow), set it as GITHUB_TOKEN above, then add the server from Settings → MCP → catalog.

API token

Stored in localStorage (key sf_token). Masked by default; 👁 to reveal, ⧉ to copy.
no pending approvals
A tool set to auto never asks. To change a tool's policy (auto / required / denied) use Impostazioni → Tool policy.
