Architecture · SparkForge v0.7.2 · single process on stdlib Python · :8790

One process. Four client surfaces. One SSE event bus.

Five client surfaces (WebUI, Orbit β, CLI, Mobile, MCP) drop onto a single server process. Inside, the API Gateway routes by HTTP method, the Agent Plane drives the LLM through assemble_turn → provider → tool loop → keepgoing, and every step is published onto /api/feed (SSE) and persisted to flat atomic JSON stores. Providers are reached via an OpenAI-compatible router. Read top-to-bottom; arrows are solid for sync calls, dashed for async / persist / SSE.
